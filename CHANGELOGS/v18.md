# v18.0.0 2026-09-12

## Notice

本版本是自上游 [Nemo2011/bilibili-api](https://github.com/Nemo2011/bilibili-api)（commit `027563d2`，v17.4.2）分叉以来的首个独立大版本，包含网络层与反爬虫体系重构、登录凭据获取修复、测试体系迁移至 pytest、全量类型检查门禁与安全加固。升级时请留意下文「行为变更注记」。

## 行为变更注记

本版本包含以下行为变更，升级时请留意：

- **异常类型变更**：原先抛裸 `Exception` 的 4 处参数/状态校验改为抛 `ArgsException`；geetest 相关（如 `get_geetest_server_url`）改抛 `GeetestException`。按异常类型捕获的调用方需同步调整。
- **超时语义统一**：请求客户端的 `timeout <= 0` 统一表示不限时（修复 httpx 中 `0.0` 为"立即超时"的相反语义）。
- **lstrip → removeprefix 输出修正**：`game` / `opus` / `interactive_video` 等处改用精确前后缀剔除，不再按字符集误删首尾字符，相关输出可能与旧版不同。
- **映射缓存有界化**：`cache_pool` 的 article ↔ dynamic 等模块级映射改为 1 小时过期、4096 条上限的 TTLCache，不再无限增长；极端情况下条目过期后再次调用会重新拉取。
- **live 拆分影响**：直播弹幕解析 `parse_*` 系列函数拆分至 `bilibili_api._live_danmaku`，monkeypatch 目标路径需相应变更；`LiveDanmaku` 实例的 pickle 序列化不保证跨版本兼容。

## 登录

- fix(login): **修复网页端二维码登录凭据获取失效**——改从轮询响应 `Set-Cookie` 构造凭据，`ac_time_value` 直接取自轮询响应的 `refresh_token`
- fix(login): `search_countries` 关键词匹配修正
- fix(login): 二维码登录凭据恢复 `ac_time_value` 必需字段校验，缺失时报错并指明缺失项（与规格 002 FR-001 对齐）

## 网络层与反爬虫

- refactor(utils): 重构网络层与反爬虫模块结构（`utils/_api.py` 入口 + `utils/_anti_spider.py` 主体实现与 `AntiSpiderCache` 参数缓存）
- feat(anti-spider): 采用 fork 的 WbiManager 并接入带锁 TTL 缓存，复用缓存 mixin_key、用 translate 表加速参数过滤
- perf(cache): `cached_async` 增加并发单飞并修复跨事件循环残留任务自愈
- fix(session): 代理改为按请求传递，消除全局 `request_settings` 竞态
- fix(clients): 修复 WebSocket 句柄泄漏与关闭后语义
- perf(api): 响应解析直接处理 bytes 并预编译 JSONP 正则
- perf(live): 心跳定时改为截止时间式以降低事件循环唤醒
- fix(session): session_pool 弱引用化治理与注销清理补齐

## 安全加固

- fix(danmaku2ass): XML 解析改用 defusedxml 防实体注入
- fix(interactive_video): 用受限评估替代 unsafe eval 以防注入
- fix(scripts): doc_gen 移除 eval 动态取 docstring 并加输出路径白名单守卫
- fix(picture): 图片后缀进入临时文件路径前做白名单过滤
- fix(ass): 弹幕导出临时文件改用 tempfile 避免固定名冲突
- fix(parse_link): 根路径及短路径链接解析防越界

- fix: 补全异常链并收紧裸 except
