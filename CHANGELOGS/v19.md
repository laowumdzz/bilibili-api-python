# v19.0.0 2026-09-25

## Notice

本版本以类型债清零为主线：pyrefly 全部 1064 条存量类型错误清零、豁免机制整体退役，类型门禁恢复对全部错误码的默认全额拦截。类型修复本身保持运行时零变化；修复过程中发现的真实 bug 均按"一事一提交"拆分独立修复（见下文），其中数处涉及可观察行为，升级时请留意「行为变更注记」。原 v18.0.1（未发布）节的两项修复并入本版。

## 行为变更注记

本版本包含以下行为变更，升级时请留意：

- **`VideoPorderMeta` / `VideoMeta`**：误用 dunder 的 `__dict__` 方法改名 `to_dict`（库内调用点已同步更新）；如外部代码曾调用该方法，请改用 `to_dict()`。
- **`VideoPorderMeta`**：商单模板参数按模板类型隔离校验，`OTHER` 类型缺参现在会抛 `ArgsException` 而非静默构造缺参载荷。
- **`VideoEditor._change_cover`**：修复对 `upload_cover` 返回值（字符串）做下标取值的问题，换封面功能恢复正常。
- **`audio_uploader` 事件名**：`PRE_COVER` / `COVER_FAILED` 事件注册补 `.value` 对齐——此前监听这两个事件的回调不会被触发，修复后开始正常派发。
- **`BuildDynamic`**：修复链式构建误传 `Vote` 对象给 `add_vote` 的问题。
- **`Session.on` 签名对齐**：参数名与父类 `AsyncEvent.on` 对齐为 `event_name`，旧名 `event_type` 经兼容垫层吸收（已 deprecate，暂不移除）。
- **`utils/upos`**：`_complete_file` 补回缺失的返回语句——此前分片合并完成后该函数的后续处理不会执行。

## 真实 bug 修复

- fix(sync): `sync()` 对 `concurrent.futures.Future` 改经 `asyncio.wrap_future` 显式转换后执行——`run_until_complete` 从不接受该类型，此前在 Linux（3.10–3.13）直接 TypeError、3.14 起全平台必现；同步移除对应用例的 3.14 skipif（原 v18.0.1 未发布项）
- fix(channel_series): 补上 `del_channel_series` 中 `get_meta` 漏掉的 `await`（此前协程直接下标必然 TypeError）
- fix(cheese): 补上 `get_danmaku` 分段计算中 `get_meta` 漏掉的 `await`
- fix(bangumi): `get_episode_list` 海外分支对缺失 `episodes` 字段空值兜底
- fix(dynamic): BuildDynamic 链式构建误传 `Vote` 对象给 `add_vote`
- fix(video_uploader): `VideoEditor._change_cover` 对 `upload_cover` 返回字符串下标取值
- fix(video_uploader): `VideoPorderMeta` 商单模板隔离与 `OTHER` 类型缺参校验
- fix(audio_uploader): `PRE_COVER` / `COVER_FAILED` 事件名补 `.value` 对齐
- fix(upos): `_complete_file` 补回缺失的返回语句

## 新增与增量 API

- feat(utils): `Api` 新增 `result_dict` / `result_list` 类型化结果访问器——中心化 isinstance 收窄（cast 处附依据注释），作为 `Api(**api).update_params(**params)` 调用链尾部的增量替换选项；`request()` / `result` 原样保留
