## ⚠️ BREAKING CHANGE

### feat(nonebot)!: 配置由 cookie 字符串改为凭据存储 uid 引用

`BILIBILI_LIVE_BOTS` 不再接受上游式 `cookie` 字符串（`sessdata` / `bili_jct` 等字段同样拒绝），账号唯一事实源改为库的加密凭据存储：配置只以 `uid` 引用存储中的账号。旧配置启动即失败，错误文本给出「写入凭据存储 + uid 引用」的迁移步骤；完整步骤见 README「从上游适配器迁移」一节。

```dotenv
# 迁移前（不再支持）
BILIBILI_LIVE_BOTS='[{"cookie": "SESSDATA=...", "room_ids": [544853]}]'

# 迁移后
BILIBILI_LIVE_BOTS='[{"uid": 10001, "room_ids": [544853]}]'
```

## 新增

### feat(nonebot): NoneBot 直播适配器

- 导入路径保持 `nonebot.adapters.bilibili_live`，实现位于 `bilibili_api.nonebot.adapters.bilibili_live`；两条路径取到同一批对象（`is` 为真），现有插件零改动。
- 41 个可实例化事件、31 个数据模型、消息与消息段、4 个适配器异常与 `Adapter` / `WebBot` / `OpenBot` 公共符号保持与上游 0.2.6 一致。
- 网络与凭据下沉：HTTP / WebSocket 经 `BiliAPIClient`，新增由 NoneBot 驱动承载的 `NoneBotClient`（HTTP + 四个 `ws_*` 方法 + 流式下载），用户的 `DRIVER` 配置继续生效；WBI / buvid / bili_ticket 复用库内集中实现。
- 多账号调度：按凭据存储插入顺序选号，凭据失效先刷新、刷新失败整号切换；失败分类表显式可测，禁止「一律重连」兜底。
- 连接时机：`on` / `auto` / `manual` 三态；`auto` 逐房间轮询开播状态，同轮相邻请求间隔 ≥ 2 秒，失败只退避不加速；50 房间规模下建连受 `max_concurrent_connects` 节流。
- 可选依赖 extra：`nonebot = ["nonebot2>=2.5.0", "betterproto>=1.2.5,<2"]`。

### fix(nonebot): 修复上游 0.2.6 三处主路径缺陷

- 网页 `DANMU_MSG`（无顶层 `data`）不再被丢弃；`cmd` 的 `:4:0:2:2:1` 一类后缀归一为主命令名。
- 醒目留言（含 `SUPER_CHAT_MESSAGE_JPN`）不再因 `message_id` / `rmb` 预求值触发 `KeyError`。
- 粉丝勋章同时接受 `is_light` 与 `is_lighted`（`is_lighted` 为规范别名），网页事件不再校验失败。

### test(nonebot): 离线回归与真实连接冒烟

- 新增 6 个离线测试文件覆盖公共符号、帧回放（41 事件类 / 48 帧样本）、三处缺陷、配置校验、多账号调度、连接时机、驱动桥接与 API 链路；1000 帧回放 ≤ 1 秒。
- 新增只读集成用例 `tests/test_nonebot_live.py`：匿名建立真实弹幕连接并收到业务帧后断开（不声明 `readonly` / `cred1`，见 research D15）。
- 帧样本来源：`tests/fixtures/nonebot_frames/`（合成最小帧 + 缺陷帧），真实帧录制脚本 `scripts/record_nonebot_frames.py`（人工执行、不入 CI、脱敏后写入不入库的 `raw/`）。
