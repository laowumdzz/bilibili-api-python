# Contract: pytest 命令行选项 `--login`

**Feature**: 001-pytest-temp-login | **Date**: 2026-08-31 | **Spec**: [spec.md](../spec.md)

本特性对用户暴露的唯一接口面：pytest 命令行选项。

## 选项定义

```text
pytest [--login <TYPE>]
```

| 项 | 值 |
|----|----|
| 参数名 | `--login` |
| 类型 | 可选，带值 |
| 合法取值 | `phone`（手机号短信验证码登录）、`qrcode`（二维码扫码登录） |
| 缺省 | 不传——行为与本特性引入前完全一致 |

## 行为契约

### C1. 传入合法值

无条件执行所选登录流程（即使 TEMP 缓存凭据仍然有效也不跳过登录）；登录成功后：

1. 以新凭据覆盖 TEMP 缓存文件（见 [cache-file-format.md](cache-file-format.md)）；
2. 本次运行以该凭据执行全部用例（凭据来源优先级第 1 位）。

### C2. 传入非法值

立即以用法错误退出（不进入用例收集、不发起任何登录、不读写缓存）。

### C3. 登录中止（用户中断 / 二维码连续 3 次超时 / 短信流程失败）

输出一条清晰提示；不写入缓存文件；已有缓存保持原状；离线用例照常执行；需凭据用例按凭据来源回退链处理（无其他来源则 skip）。

### C4. 不传 `--login` 的普通运行

每次运行尝试读取 TEMP 缓存文件作为凭据来源（优先级第 2 位，高于 `BILI_*` 环境变量与 `.bilibili.cookie`），其降级语义为：

| 缓存状态 | 行为 |
|---------|------|
| 文件缺失 | 一条提示；回退既有来源；最终无凭据 → skip |
| 内容不合法 | 一条错误 + 删除文件；回退既有来源；最终无凭据 → skip |
| 合法且 `check_valid()` 通过 | 直接使用，执行全部用例，零交互 |
| 合法但过期 | 尝试 `refresh()`：成功 → 用新凭据并回写缓存；失败 → 一条警告 + 删除文件 + 回退，最终无凭据 → skip |
| 有效性无法验证（网络异常） | 一条提示 + skip 需凭据用例，**不删除**文件 |

### C5. 交互边界

仅当显式传入 `--login` 时允许出现终端交互（二维码展示、浏览器极验链接、手机号/验证码输入）；普通运行绝不交互。

### C6. 输出安全

所有提示 / 错误 / 警告消息仅含状态描述，不含任何凭据字段值。

## 非目标

- 不提供密码登录通道；
- 不改变库（`bilibili_api/`）任何公开接口；
- 不管理多账号并存（固定缓存文件名，后登录覆盖先登录）。
