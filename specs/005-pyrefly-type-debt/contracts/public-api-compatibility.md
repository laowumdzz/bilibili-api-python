# Contract: 公共 API 兼容（本特性期间不变式）

**Feature**: 005-pyrefly-type-debt | **Kind**: 库对外接口契约

本特性是纯类型层修复。对库的下游使用者，以下契约在整个特性生命周期内
必须成立；任何批次若无法满足，须停下来按 spec FR-005 单独评估。

## 不变式（MUST NOT 变更）

以下均为**运行时可观察**的兼容面：

1. **公共符号集合**：`bilibili_api` 各模块现有公开类、函数、方法、异常
   不删除、不改名。
2. **参数**：公共函数/方法的参数名（关键字调用面）、参数顺序、默认值
   不变；不删除参数。
3. **运行时行为**：函数返回值内容、异常类型与触发条件、副作用（网络
   请求、状态变更）不变。
4. **异步形态**：现有 `async def` 不改同步、反之亦然；`@sync` 包装面不变。

## 允许的变更（MUST 满足全部三个条件）

1. **注解修正/放宽**：现有函数的类型注解向真实行为靠拢（如
   `year: str = -1` → `year: str | int = -1`；返回 `dict` → `dict | list`
   仅当运行时确可返回 list）。此类变更不改运行时，逐例在批次提交说明
   中记录（data-model: RealBugSplit.compat_impact = 类型层纠错）。
2. **纯增量新增**：新增 `Api` 类型化结果访问器（research.md R2）等内部
   需要的新公共/内部符号。新增须带完整中文 docstring 与类型注解
   （宪法 III）。
3. **注释与文档**：`docs/modules/` 经 `doc_gen.py` 再生（宪法 III，
   禁止手编）。

## 已知雷区（处置预案见 research.md R6）

| 符号 | 风险 | 预案 |
|------|------|------|
| `Session.on(event_type=...)` | 与父类参数名对齐时可能破坏关键字调用 | 对齐 + 兼容垫层优先；全库检索确认无调用方可直接改名；最后手段局部忽略 |
| `VideoPorderMeta.__dict__` / `VideoMeta.__dict__`（方法） | 改名/移除影响显式调用点 | 全库检索；预期为死代码（属性访问走类型槽位） |

## 违约处置

- 发现必须改运行时行为才能修复的类型错误 → 行为修复拆独立提交，
  单独评审（宪法 V"一事一提交"）；
- 无法避免的破坏性变更 → `BREAKING CHANGE` footer（本特性目标为零，
  spec FR-005）；
- 验证方式：每批次 `uv run pytest -m "not integration"` 全绿 +
  quickstart.md 场景 4 的对外签名抽查。
